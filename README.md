# MINA Marketplace

A technology-focused marketplace built around verified digital products.

## Project Structure

- docs/       Architecture, APIs, screens and documentation.
- database/   SQL schemas, migrations, RLS and seed data.
- design/     Design system, tokens and visual boards.
- planning/   Features, traceability and validation records.
- app/        Application source code.
- tests/      Automated tests.
- reports/    Technical reports.

## Project Status

Design and technical documentation are available.
Application implementation status must be verified separately.

## Important

Do not assume that documented features are implemented.
Review existing architecture and database contracts before development.
